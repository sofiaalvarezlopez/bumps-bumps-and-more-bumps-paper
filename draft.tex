\section{Methods}\label{sec:methods}

We analyze 259 events from \acs{GWTC-5} with false-alarm rates below $1\,\mathrm{yr}^{-1}$~\citep{LIGOScientific:2026wfs}, using the individual-event posterior samples publicly released by the \acs{LVK} collaboration~\citep{ligo_scientific_collaboration_and_virgo_2026_20348005,ligo_scientific_collaboration_and_virgo_2026_20348006}. For events in \acs{GWTC-3} and earlier catalogs, we use posterior samples generated with the \textsc{IMRPhenomXPHM} waveform model~\citep{Pratten:2020ceb}. For events in \acs{GWTC-4} and \acs{GWTC-5}, we use \textsc{NRSur7dq4} samples when available and \textsc{IMRPhenomXPHM-SpinTaylor} samples otherwise. Although our waveform choices differ slightly from those of~\citet{LIGOScientific:2026wfs}, they increase the number of posterior samples per event from \textcolor{red}{1993} to 6913, reducing the parameter-estimation contribution to the log-likelihood variance. We do not expect the differences in waveform choices to significantly affect population inference.

We infer population properties using the standard hierarchical Bayesian framework for gravitational-wave population inference~\citep{Mandel:2018mve,Thrane:2018qnx,Vitale:2020aaz,Essick:2023upv}. We account for selection effects by computing sensitivity estimates for \acs{BBH} systems over O1--O4b via a simulation campaign~\citep{Essick:2025zed,ligo_scientific_collaboration_2026_19500052}. We evaluate the population likelihood using Monte Carlo integration and limit the variance of the log-likelihood estimate to be less than one during inference~\citep{Tiwari:2017ndi,Essick:2022ojx,Talbot:2023pex,Heinzel:2025ogf}.

We analyze the population using two mixture models, each combining parametric components with a flexible component described by either \PixelPop~\citep{Heinzel:2024jlc} or \Bsplines~\citep{Edelman:2021zkw,Edelman:2022ydv,Godfrey:2023oxb}. We refer to these models as \PPMixture and \BsplMixture, respectively.
